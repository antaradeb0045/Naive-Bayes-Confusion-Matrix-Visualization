# Naive Bayes Iris Classifier (Binary Classification)

## 📌 Overview
This project implements a Gaussian Naive Bayes classifier to perform binary classification on the Iris dataset. The model identifies whether a flower belongs to the Setosa class or not.

## 🎯 Objective
- Convert multi-class Iris dataset into binary classification
- Apply Naive Bayes algorithm
- Evaluate model performance
- Visualize results using confusion matrix heatmap

## 🚀 Features
- Binary classification (Setosa vs Not Setosa)
- Gaussian Naive Bayes model
- Accuracy, confusion matrix, classification report
- Heatmap visualization using Seaborn

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📂 Dataset
- Source: Iris dataset (from UCI repository via GitHub)
- Features:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width
- Target:
  - 1 = Setosa
  - 0 = Not Setosa
